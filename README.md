An interactive **Hospital Emergency Room Dashboard** built in **Microsoft Excel** to analyze patient visits, waiting time, admission status, department referrals, and overall emergency room performance.

# 📌 Project Overview

This project transforms raw hospital emergency room data into an interactive dashboard using Microsoft Excel.

The dashboard enables hospital management to monitor patient flow, identify operational bottlenecks, and make informed decisions using data visualization and key performance indicators (KPIs).

---

# 🎯 Objectives

- Analyze emergency room performance
- Monitor patient admissions
- Track average waiting time
- Measure patient satisfaction
- Analyze referrals across departments
- Understand patient demographics

---

# 📈 Key Performance Indicators (KPIs)

- 👨‍⚕️ Total Patients
- ⏱ Average Wait Time
- ⭐ Patient Satisfaction Score
- 📋 Admission Status
- 🚑 Department Referrals
- 👥 Patient Gender Distribution
- 👶 Patient Age Group Analysis
- ⌛ Attendance Time (On Time vs Delay)
